# Services

The API consists of 17 sections. Each one has its own purpose and use case. These are detailed below:

1. **APOD** - Astronomy Picture of the Day
2. **Asteroids NeoWs** - Near Earth Object Web Service
3. **DONKI** - Space Weather Database Of Notifications, Knowledge, Information
4. **Earth** - Unlock the significant public investment in earth observation data
5. **EONET** - The Earth Observatory Natural Event Tracker
6. **EPIC** - Earth Polychromatic Imaging Camera
7. **Exoplanet** - Programmatic access to NASA's Exoplanet Archive database
8. **Open Science Data Repository** - Programmatic interface for the Open Science Data Repository website
9. **Insight** - Mars Weather Service API
10. **Mars Rover Photos** - Image data gathered by NASA's Curiosity, Opportunity, and Spirit rovers on Mars
11. **NASA Image and Video Library** - API to access the NASA Image and Video Library site at [images.nasa.gov](https://images.nasa.gov)
12. **TechTransfer** - Patents, Software, and Tech Transfer Reports
13. **[Satellite Situation Center](ssc/index.md)** - System to cast geocenric spacecraft location information into a framework of (empirical) geophysical regions
14. **SSD/CNEOS** - Solar System Dynamics and Center for Near-Earth Object Studies
15. **Techport** - API to make NASA technology project data available in a machine-readable format
16. **TLE API** - Two line element data for earth-orbiting objects at a givien point in time
17. **Vesta/Moon/Mars Trek WMTS** - A Web Map Tile Service for the Vesta, Moon, and Mars Trek imagery projects
