# Rovers and Cameras

The api has support for 4 Mars Rovers:

1. Perseverance
2. Curiosity
3. Opportunity
4. Spirit

!!! note
    While the API supports both the Opportunity and Spirit Rovers, NASA has removed the Raw images of these rovers from the services, meaning that you cannot get images for these Rovers. Since the Rovers are still supported by the API, they have a space in this documentation.

## Curiosity
![Curiosity Picture](https://github.com/corincerami/mars-photo-api/blob/b17a2a2fd9c42d6f7aee92eb53ac2e6d5b9996e4/public/explore/images/Curiosity_rover.jpg?raw=true)

Information about Curiosity

| Key      | Value              |
| -------- | ------------------ |
| Launched | November 26th 2011 |
| Landed   | August 5th 2012    |  

This rover has a total of 7 cameras onboard. All of which can be queried using the API.

<div class="grid cards" markdown>

- __FHAZ__ Font Hazard Avoidance Camera
- __RHAZ__ Rear Hazard Avoidance Camera
- __MAST__ Mast Camera
- __CHEMCAM__ Chemistry and Camera Complex
- __MAHLI__ Mars Hard Lens Imager
- __MARDI__ Mars Descent Imager
- __NAVCAM__ Navigation Camera

</div>
