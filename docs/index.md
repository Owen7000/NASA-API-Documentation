# NASA API Documentation

---

In the initial analysis of an upcoming project, I discovered that the NASA API documentation is a bit all over the place. So I took it upon myself to create an all-in-one documentation for all routes and services.

!!! warning
    Please note that this is not an official NASA document or project. I am a hobbyist who wanted a better, centralised location for API documentation. If there is anything wrong in here, please either create an issue to let me know, or submit a pull request to fix it! Thank you :)

This documentation site is still in development, so please check back regularly to ensure that the information is still accurate.
